# เช็กลิสต์ก่อนเปิดให้นักศึกษา

ไล่จากบนลงล่าง · ทุกข้อที่ขึ้นต้นด้วย **[ต้องผ่าน]** คือข้อที่ถ้าไม่ผ่านแล้ว
นักศึกษาจะทำงานไม่ได้ · ข้อที่ขึ้นต้นด้วย **[ดีถ้ามี]** คือข้อที่ขาดได้
โดยงานยังเดินต่อได้ แค่เสียข้อมูลหรือความแข็งแรงบางส่วน

## 1. ตัวระบบ

- **[ต้องผ่าน]** เปิด `https://ai-literacy-th.vercel.app/` ตรง ๆ จากเบราว์เซอร์ที่ไม่ได้
  ล็อกอิน Canvas → ต้องเจอหน้า **"กรุณาเข้าผ่าน Canvas"**
  ถ้าเข้าทำแบบประเมินได้เลย แปลว่าโหมดยังไม่ใช่ lti หรือโดเมนไม่อยู่ใน `connectHosts`
- **[ต้องผ่าน]** เปิดโดเมนสาธารณะ (ถ้ามี) → ต้องทำได้ตามปกติและ**ไม่มี**ปุ่มส่งผล
- **[ดีถ้ามี]** `npm test` ผ่านทั้งชุด

## 2. Canvas (ทำต่อรายวิชา — ดู `canvas-course-setup.md`)

- **[ต้องผ่าน]** เพิ่มแอปเข้ารายวิชาด้วย consumer key / shared secret ที่ตรงกับ
  env vars บน Vercel
- **[ต้องผ่าน]** Assignment ที่ 1 ตั้ง **Submission Type = External Tool** ชี้ไปที่แอป
  (ไม่ใช่ External URL — ถ้าใช้ URL ธรรมดา ระบบจะไม่ได้อีเมลจาก Canvas)
- **[ต้องผ่าน]** Assignment ที่ 2 ตั้ง **Submission Type = External URL** ชี้ไปที่ MS Form
- **[ต้องผ่าน]** กด Publish ทั้งสอง assignment

## 3. ทดสอบด้วยบัญชีนักศึกษาจริง 1 คน — ข้อนี้แทนข้ออื่นไม่ได้

เข้าจาก Canvas แล้วทำให้จบทั้งเส้น:

- **[ต้องผ่าน]** เข้าได้โดยไม่เจอหน้ากั้น (ถ้าเจอ → อีเมลไม่อยู่ใน `ALLOWLIST`)
- **[ต้องผ่าน]** เลือกกลุ่มสาขาได้ และตัวอย่างใต้คำถามเปลี่ยนตามสาขา
- **[ต้องผ่าน]** ทำครบ 36 ข้อแล้วเห็นหน้าผล
- **[ต้องผ่าน]** กด `📤 ส่งผลให้ผู้สอน` แล้วได้ **รหัสยืนยัน 8 ตัวอักษร**
- **[ต้องผ่าน]** มีแถวใหม่ใน Google Sheet และ**รหัสในแถวตรงกับที่เห็นบนหน้าจอ**
- **[ต้องผ่าน]** กด `เปิดแบบสะท้อนคิด →` แล้ว MS Form เปิดขึ้นโดย**ข้อ 1–4 กรอกมาให้แล้ว**
- **[ต้องผ่าน]** ส่ง MS Form แล้วมีแถวใหม่ในไฟล์ผลของฟอร์ม
- **[ดีถ้ามี]** คะแนนขึ้นใน Canvas Gradebook อัตโนมัติ

## 4. ข้อมูลที่จะได้ (เช็กก่อนเปิด ไม่งั้นเก็บย้อนหลังไม่ได้)

- **[ดีถ้ามี]** `discipline` กับ `fieldScore` มี entry ID ใน `connect-config.js`
  ถ้าเว้นว่าง สองช่องนี้**จะไม่เข้า Sheet** และจะแยกผลรายกลุ่มสาขาไม่ได้เลย
  วิธีทำ: เพิ่มคำถาม Short answer 2 ข้อในฟอร์ม → ดู entry ID → ใส่ในคอนฟิก
- **[ดีถ้ามี]** Upstash Redis — กันการยิงลิงก์ซ้ำข้ามเครื่อง
  ถ้าไม่มี ระบบเก็บตั๋วไว้ในหน่วยความจำของแต่ละเครื่อง ยังกันได้บางส่วน

## 5. ถ้าพรุ่งนี้ Canvas ไม่ยอม — ทางสำรอง

สลับไป **โหมด form** ได้ด้วยการแก้บรรทัดเดียวใน `content/connect-config.js`:

```js
mode: "form",   // เดิม "lti"
```

ได้: หน้าแบบประเมินเปิดจากลิงก์ธรรมดา · มีช่องกรอกรหัสนักศึกษา ·
**ยังมีรหัสยืนยัน** (เบราว์เซอร์สร้างเอง เขียนลง Sheet แถวเดียวกัน) ·
ปุ่มเข้าแบบสะท้อนคิดและ prefill ยังทำงาน · ตรวจงานจับคู่ด้วยรหัสได้เหมือนเดิม

เสีย: ไม่มีการยืนยันตัวตนจาก Canvas (ใช้รหัสนักศึกษาที่กรอกเองแทน) ·
ไม่ส่งคะแนนเข้า Canvas อัตโนมัติ · รหัสยืนยันเป็นตัวจับคู่ ไม่ใช่หลักฐานกันปลอม

> อย่าสลับไปโหมดสาธารณะ (zero-data) ถ้ายังต้องตรวจงานสะท้อนคิด — โหมดนั้น
> ไม่มีการส่งผล จึงไม่มีรหัสยืนยัน และไม่มีปุ่มเข้าแบบสะท้อนคิด
